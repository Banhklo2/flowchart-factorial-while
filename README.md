## ✅ 시나리오: 팩토리얼 계산 시스템

- 사용자가 **1 이상의 정수 숫자**를 입력한다.
- 사용자가 **입력한 숫자의 팩토리얼(n!)을 계산하여 출력한다.**
- 프로그램 종료 시 **팩토리얼 계산이 완료되었음을 알린다.**

## 📌 입력 / 출력 정리

### 입력(Input)
- 사용자가 입력하는 정수 `num`

### 출력(Output)
- num! (팩토리얼 계산 결과)

### 상태(State)
- `num` : 입력받은 정수  
- `result` : 누적 곱셈 결과

---

## 🔎 조건 정리

### 종료 조건
- num이 1보다 작아지면 종료
  
### 분기 조건
- 입력값이 1 이상의 정수인가?

### 예외 / 에러 조건
- 숫자가 아닌 값이 입력된 경우  
  → `"정수를 입력하세요"` 출력 후 다시 입력받기  
- num < 1 인 경우  
  → `"1 이상의 정수를 입력하세요"` 출력 후 다시 입력받기  

---

## 🔁 로직 흐름 설계

1. 시작 시 한 번만 실행  
   - `result = 1` 로 초기화한다.

2. 반복

   1) `num`을 입력받는다.  
   2) 입력값이 1 이상의 정수인지 확인한다.  
      - 예 → 팩토리얼 계산 반복 시작  
      - 아니오 → `"1 이상의 정수를 입력하세요"` 출력 후 다시 입력받기  
   3) `result = result * num` 을 수행한다.  
   4) `num = num - 1` 로 상태를 업데이트한다.  

3. 종료 시  
- 팩토리얼 계산 결과를 출력한다.  
- 프로그램을 종료한다.
